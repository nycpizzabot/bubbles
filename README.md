# Bubbles

A tiny browser toy: click anywhere and release a burst of glowing bubbles that float away. This repo is deliberately small and has no build system.

## What this explores

- Creating DOM elements from pointer coordinates
- CSS keyframe animation with randomized timing
- Lightweight visual feedback without a framework
- The value of a finished interaction that does one thing well

## Run it

Open `index.html` in a browser, or serve the directory:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

There is no backend, dependency install, or data storage. The experiment is the interaction itself.
